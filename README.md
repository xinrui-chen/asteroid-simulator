# 🚀 Asteroid Typing Game
A Python arcade-style typing game built with the turtle graphics module. Control a spaceship to collect asteroids with letters and spell out randomly selected space-themed words before the timer runs out!

![image](https://github.com/user-attachments/assets/06b7e149-acb8-44df-b565-d8784ae5fec6)

## Features
Random space-themed word generation

Real-time spaceship control

Collision detection between ship and asteroids

⏱Countdown timer and scoring system

Classic arcade-inspired gameplay

Built entirely with Python's built-in turtle module (no external dependencies!)

## How to Play
Run the game.

Use arrow keys to steer your spaceship.

Collect the letters from falling asteroids in order to spell the given word.

Finish before the timer ends!

Get a new word and try again — how many can you get?

## Built With
Python 3.x

turtle – for graphics and user interaction

Classic game development logic (state, input handling, physics, etc.)
